# KahveCell frontend

React, TypeScript ve Vite ile hazırlanmış KahveCell arayüzü.
- Kurulum: `npm install`
- Geliştirme sunucusu: `npm run dev`
- Kontroller: `npm run lint` ve `npm run build`
- API adresi: `VITE_API_BASE_URL` değişkenini `.env.local` dosyasında ayarlayın.
- Projenin genel kurulumu ve mimarisi için [kök README](../README.md) dosyasına bakın.
